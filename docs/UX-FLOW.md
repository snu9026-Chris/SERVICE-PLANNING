# UX Flow — 대시보드 확장

> 이 프로그램(blueprint)을 써서 아이디어 → 제품이 나오기까지. 대화하며 단계마다 대시보드가 채워져요.

## 1. 아이디어 꺼내기
> 막연한 생각을 Claude와 정리해 "뭘 만들지" 윤곽을 잡아요.
- 시안: webview-spec-product.html
- 묻기: 무슨 문제를 풀고 싶어요? 누구를 위해? 웹·앱·확장 중 뭐로?
- 정하기: 문제 · 타깃 · 만들 형태의 초안
- 채워짐: Spec 탭에 첫 문서가 생김
- 산출물: docs/INQUIRY.md
### 기능
- 문서 모아보기 — 기획·디자인·구조 문서를 폴더처럼 펼쳐봐요 [완료]
- 만들 형태 배지 — 웹·앱·확장 중 뭘 만드는지 맨 위에 배지로 보여줘요 [완료]

## 2. 무엇을 만들지 정하기
> 핵심 한 줄, 누구를 위한 건지, 그리고 "안 만들 것"까지 못박아요.
- 시안: webview-plan.html
- 묻기: 한 줄로 뭐예요? 꼭 되는 핵심은? 일부러 안 할 건? 배포는 어떻게?
- 정하기: 핵심 기능 · 타깃 · 안 만들 것(NON-GOALS) · 산출물 형태
- 채워짐: Spec의 PRODUCT + Plan "지금 만드는 것" + 사이드바 배지
- 산출물: docs/PRODUCT.md
### 기능
- 전체 로드맵 — 계획 전체를 보여주고 지금 단계를 밝게 강조해요 [완료]
- 지금 만드는 것 — 이 프로젝트가 뭔지 한 줄로 적어둬요 [완료]
- 안 만들 것 표시 — 일부러 안 하기로 한 건 따로 구분해줘요 [완료]
- 빠뜨린 것 알림 — 이번 단계에서 안 끝낸 게 있으면 위에 알려줘요 [완료]

## 3. 화면·디자인 잡기
> 색·글꼴부터 화면별 구성·사용자 여정까지 같이 정하고 시안을 만들어요.
- 시안: webview-spec-design.html
- 묻기: 색·글꼴 느낌은? 이 화면은 어떤 상황에 봐요? 처음 들어와 순서대로 뭘 하죠?
- 정하기: 디자인 시스템 + 화면별 컴포넌트 + 사용자 여정
- 채워짐: Preview 갤러리에 시안 + UX Flow 탭
- 산출물: docs/DESIGN.md · 시안 HTML · docs/UX-FLOW.md
### 기능
- 색·글꼴 견본 — 디자인 문서 속 색과 글꼴을 자동으로 보여줘요 [완료]
- 시안 갤러리 — 만들어 둔 디자인을 카드로 죽 보여줘요 [완료]
- 눌러서 크게 — 카드를 누르면 화면 가득 펼쳐 봐요 [완료]
- 이전/다음 — 화살표로 시안을 넘겨가며 봐요 [완료]

## 4. 구조 잡기
> 코딩 전에 기술 뼈대·경계·계획을 확정해요 (CEO·디자인·엔지니어 리뷰 묶음).
- 시안: webview-spec-architecture.html
- 묻기: 어떤 스택? 어디까지가 한 덩어리(도메인)? 데이터는 어떻게 주고받죠?
- 정하기: 스택 · 도메인 경계 · 데이터 계약 · 성능 예산
- 채워짐: Spec의 ARCHITECTURE
- 산출물: docs/ARCHITECTURE.md · plans/*.md
### 기능
- 문서 탐색기 — ARCHITECTURE 문서를 섹션 단위로 펼쳐봐요 [완료]
- 도메인 맵 — 코드 경계와 규칙을 한눈에 [완료]
- 계획 연결 — plans 문서와 현재 단계를 이어줘요 [완료]

## 5. 만들기
> 확정한 시안·구조를 따라 실제 코드를 짜요 (막히면 디버깅·외부 리뷰).
- 시안: sidebar.html
- 묻기: 이 기능 따르는 승인 시안 맞죠? 막힌 부분 원인부터 볼까요?
- 정하기: 따르는 디자인 계약 · 구현 순서
- 채워짐: 사이드바 진행률이 올라감
- 산출물: 소스 코드 (PRODUCT·ARCHITECTURE 비면 시작 차단)
### 기능
- 자동으로 켜짐 — 폴더를 열면 옆에 대시보드가 저절로 나타나요 [완료]
- 지금 어디쯤 — 현재 단계와 진행률을 맨 위에 크게 보여줘요 [완료]
- 점검 알림 — 점검할 때가 되면 아이콘에 빨간 점이 떠요 [완료]

## 6. 점검·출시
> 코드·디자인·사용성을 점검하고, 빠진 것 없이 출시·마무리해요.
- 시안: webview-errors.html
- 묻기: 구현이 승인 시안과 맞나? 사용성 점검할까? QA 후 출시할까?
- 정하기: 고칠 점 · ADR 기록 · 출시 여부
- 채워짐: QA · Errors 탭, 완료 표시
- 산출물: docs/adr · 머지된 PR · 배포된 앱
### 기능
- 오류 기록 — 에러가 났던 내용을 모아서 보여줘요 [완료]
- 출시 전 점검 — 빠진 게 없나 체크리스트로 확인 [완료]
- 사용법 안내 — 단계별로 어떻게 쓰는지 가이드 [완료]
